# SG_System

A simple console-based user management system built with Python.

This is my first OOP project where I practice classes and user input handling.

## ✨ Features
- Create a user profile
- Collects: Username, Password, Phone, Email, Country
- Confirmation step for each input to avoid mistakes
- Displays user information at the end

## 🚀 How to Run
1. Make sure you have Python installed
2. Run the file:
```bash
python main.py
